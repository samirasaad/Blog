# 📝 Blog

**Blog** is a modern blog platform built with **Next.js** and **React**, designed for fast performance, SEO-friendly pages, and easy content management.

This project is bootstrapped with **create-next-app** and ready for deployment on platforms like **Vercel**.

## 🚀 Features

- Built with **Next.js** & **React**
- Server-side rendering for SEO
- API routes for backend logic
- Modular folder structure
- SCSS support for styling
- Ready for dynamic content
- Responsive design

---

## 🧰 Tech Stack

| Category           | Technology                   |
|-------------------|-----------------------------|
| Frontend Framework | Next.js                     |
| UI Library         | React                       |
| Styling            | SCSS                        |
| Routing            | Next.js File-based Routing  |
| API Routes         | Next.js API                  |
| HTTP Requests      | Axios / Fetch API           |
| Package Management | npm / Yarn                  |
| Language           | JavaScript (ES6+)           |
| Build Tool         | Vercel / Next.js CLI        |
| Version Control    | Git / GitHub                |
